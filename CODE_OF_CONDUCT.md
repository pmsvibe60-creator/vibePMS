# Community code of conduct

Be respectful, constructive and patient. Critique ideas and code, not people.
Harassment, threats, discrimination, spam and disclosure of private information
are not welcome. Do not post tenant data or attempt to identify pseudonymous
contributors.

These expectations apply to this project's issues, pull requests and discussions.
Maintainers may edit or remove harmful content, close disruptive threads and block
repeat offenders. Moderation should be proportional and consistent.

Report abuse privately using GitHub's Report content controls. Do not reproduce
private information in a public report. For software vulnerabilities, follow
[SECURITY.md](SECURITY.md).
