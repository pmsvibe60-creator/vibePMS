04 / YOUR ASSISTANT, YOUR PROPERTIES

Manage your rentals.
From a conversation.

Connect a compatible AI client to Twenty’s MCP server to work with property records in plain English. Keep the dashboard available whenever you want a visual overview.

  1. 01

    Open your Twenty settings.

    After installing vibePMS and provisioning its fields, look for Settings → AI → MCP in your Twenty workspace. Check MCP availability in your installed version.

  2. 02

    Connect your AI client.

    Add Twenty as a remote MCP server using your client’s connection settings. Use your own Twenty workspace URL with /mcp appended, then authorize with OAuth where supported.

  3. 03

    Start with a question.

    Ask the assistant to discover your property objects and show a read-only summary. Review its first results against your records before asking it to make changes.

YOUR CONNECTION ADDRESS

Use your Twenty workspace.

https://your-twenty-domain.example/mcp

Records through MCP. Workflows through vibePMS.

Twenty MCP provides record access. Signing, invoicing and payment processing also depend on the vibePMS sidecar, webhooks and configured services. A status edit can trigger a workflow; changing an invoice to “paid” does not collect or verify money.

Connect, then verify.

MCP access has not yet been tested end to end with vibePMS’s pinned Twenty image. Start with fictional data. Ask the assistant to explain proposed changes and confirm what its connected tools can actually do.

THE USEFUL DETAILS

Before you fork.

Do I need coding experience?+

You can start with plain-English instructions and let Codex or Claude Code handle code changes. You’ll still need to create accounts, approve hosting costs and follow the setup checks. This early preview may need troubleshooting; your assistant can help diagnose problems and report reproducible bugs in GitHub Issues.

Is this a finished property management app?+

It’s a starter kit: Twenty CRM provides the operator interface and records, while the TypeScript sidecar adds rental workflows. Your AI assistant can help configure the services and adapt the code. Test your own setup before using it with real tenants.

What’s free, and what needs an account?+

The original vibePMS code is MIT licensed. Hosting, email and payment services are separate and may cost money. Twenty and other dependencies retain their own licenses. The CasaPay integration requires a separate account.

Can I adapt it to my market?+

Yes. vibePMS is a starting point for builders worldwide. Adapt the language, contract templates, rental rules and integrations to your market, and review local requirements before launch.

Can I help build it?+

Yes. Browse the open issues, read the contribution guide, or start a conversation in Discussions.
